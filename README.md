# JEMA Memorial Pre & Primary School

Official website for **JEMA Memorial Pre & Primary School** — Napupa Ward, Masasi Town Council, Mtwara Region.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

School copy and fees live in `lib/content.ts` (sourced from the 2026 school profile brochure). Images are in `public/images/`.
